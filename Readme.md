**TechCrush First coding project

==A simple calculator==

A Node.js calculator application that demonstrates the use of local (built-in), third-party, and custom modules. The application should include the following features:

-Import and use a local (built-in) Node.js module.
-Install and use a third-party module from npm.
-Create and import your own custom modules - CJS or ESM
-It should take in input from the terminal. Those inputs are what you will use as parameters for your modules/function. I.e. no static values for your numbers
-Use the functionality provided by the different modules in your application.
